# NexVita Assets

Public static assets approved for official NexVita communications.

## Email assets

- Standard wordmark: `email/nexvita-wordmark.png` — 184 × 44 px
- Retina wordmark: `email/nexvita-wordmark@2x.png` — 368 × 88 px
- Apple Mail lockup: `email/nexvita-email-lockup.png` — 184 × 76 px

Use the Apple Mail lockup for the copy-and-paste signature flow. It combines
the wordmark and tagline in one physically sized image so Mail cannot separate
them or ignore CSS dimensions. Use the Retina wordmark only where the client
reliably preserves explicit HTML image dimensions.
