# NexVita Assets

Public static assets approved for official NexVita communications.

## Email wordmark

- Standard: `email/nexvita-wordmark.png` — 184 × 44 px
- Retina: `email/nexvita-wordmark@2x.png` — 368 × 88 px

For email signatures, use the Retina asset with explicit HTML dimensions
`width="184" height="44"` so high-density displays render it sharply.
