# NexVita Assets

Public static assets approved for official NexVita communications.

## Email assets

- Standard wordmark: `email/nexvita-wordmark.png` — 184 × 44 px
- Gmail v2 wordmark: `email/nexvita-wordmark-gmail-v2.png` — 184 × 44 px
- Retina wordmark: `email/nexvita-wordmark@2x.png` — 368 × 88 px
- Apple Mail lockup: `email/nexvita-email-lockup.png` — 184 × 76 px

Use the versioned Gmail asset instead of Base64/data URIs. Its distinct URL
also avoids reusing a stale negative entry in Google's image-proxy cache. Use
the Apple Mail lockup for the copy-and-paste signature flow when logo and
tagline must remain physically joined. Use the Retina wordmark only where the
client reliably preserves explicit HTML image dimensions.
